### 🚇 [MetroRoute Intelligence](https://github.com/Enock02333/metroroute-intelligence)

A production-oriented transit analytics and decision-support platform for estimating passenger transfer routes, waiting time, expected flow, and congestion risk from anonymized fare-card and train-operation data.

**Highlights**

- Probabilistic passenger-route assignment
- Route ambiguity and uncertainty analysis
- Station and transfer-risk monitoring
- Dynamic 5-minute and 15-minute operational views
- Model evaluation and error analysis
- Responsive production interface
- Structured testing, documentation, and deployment

**Technology:** Python, data analytics, Next.js, React, Git/GitHub, Vercel

**Live application:** [metroroute-intelligence.vercel.app](https://metroroute-intelligence.vercel.app)
